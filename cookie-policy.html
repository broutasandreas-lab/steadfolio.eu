How SteadFolio uses cookies

A cookie is a small text file a website stores in your browser so it can remember things between visits. On steadfolio.eu, cookies fall into two groups: one essential cookie that remembers your consent choice, and optional analytics cookies that are only set if you accept them. For how we handle personal data more broadly, see our Privacy Policy.

Optional analytics

If you accept analytics, SteadFolio loads two tools - Google Analytics and Microsoft Clarity. Both are optional and only loaded after you accept; nothing from either tool is fetched or set before that, or if you reject. Rejecting analytics doesn't break SteadFolio - it only means these two tools aren't used.

Google Analytics helps us understand which pages are used and how visitors move through the site.

Microsoft Clarity helps us understand navigation and interaction patterns so we can improve the experience.

Google Analytics

We use Google Analytics 4 (via Google's gtag.js) to measure site usage. Google Consent Mode is implemented: analytics storage defaults to "denied" until you accept, and advertising storage (ad storage, ad user data, ad personalization) is always kept "denied" regardless of your choice.

CookieProviderPurposeDurationWhen set
_ga Google Analytics Distinguishes one visitor from another. Up to 2 years (per Google's default; most browsers cap first-party cookies at roughly 13 months in practice) Only after you accept analytics.
_ga_<container-id> Google Analytics Persists session state for this specific GA4 property. Up to 2 years (same browser cap as above may apply) Only after you accept analytics.

The exact set of cookies Google sets can change as Google updates gtag.js, and browsers may enforce their own maximum cookie lifetime shorter than the value Google requests. We're describing Google's documented default behavior rather than guaranteeing a fixed expiry.

Microsoft Clarity

We use Microsoft Clarity to see aggregated navigation and interaction patterns (for example, which pages get visited) so we can improve the site. Clarity's script and its Consent API v2 are only loaded after you accept analytics; while consent is denied, Clarity is not fetched and does not set cookies.

Because advertising consent on SteadFolio always stays denied, we do not enable the advertising-linked identifiers Clarity can otherwise use (such as MUID, SM, ANONCHK, or MR, which Microsoft documents as tied to cross-site advertising signals). The cookies below are the ones Microsoft documents as part of Clarity's own session/analytics measurement, which may be set once you accept analytics:

CookieProviderPurposeDurationWhen set
_clck Microsoft Clarity Persists a Clarity user identifier and preferences for this site, so behavior across visits can be attributed to the same browser. 1 year (per Microsoft's documentation) Only after you accept analytics.
_clsk Microsoft Clarity Connects multiple page views into a single Clarity session recording. 1 day (per Microsoft's documentation) Only after you accept analytics.
CLID Microsoft Clarity Records the first time Clarity saw this browser on any site using Clarity. 1 year (per Microsoft's documentation) Only after you accept analytics.

Microsoft maintains its own cookie documentation, which can change; we've described it as accurately as we can rather than inventing figures. If Microsoft changes what Clarity sets, this page will be updated to match.

Your choices

When you first visit steadfolio.eu, a banner asks whether you'd like to accept or reject optional analytics cookies. Essential functionality works the same either way.

Use the "Cookie settings" button at the top of this page, or the "Cookie settings" link in the site footer, to reopen that choice at any time and switch between accepting and rejecting analytics. This opens the existing consent banner - there's no separate settings screen to keep in sync.

Your choice is shared between steadfolio.eu and app.steadfolio.eu, so you're normally not asked twice when you move between the marketing site and the app.
